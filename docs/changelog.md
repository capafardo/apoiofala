# Changelog - CAA-Lab

Todas as alterações relevantes neste projeto serão documentadas neste arquivo.

## [Não Lançado] - 2026-08-30
### Adicionado
- Mais de 70 novos pictogramas vetoriais SVG locais para cobrir todas as categorias (Comunicar, Necessidades, Pessoas, Lugares, Brincar, Mais, etc.).
- Biblioteca geral de símbolos com busca e seleção múltipla.
- Funcionalidade interativa de Arrastar e Soltar (Drag-and-Drop) para personalização de pranchas por perfil de criança.
- Criação e gestão de novos perfis com suporte a apelido da criança e da mãe/acompanhante.
- Seletor dinâmico de perfil no Modo Criança, aplicando preferências visuais e pranchas customizadas.
- 28 testes automatizados cobrindo todo o sistema.
